# Security

Plugin Lab makes no network requests. It reads the files of installed plugins, writes notes and images into your vault, and — only during a capture run and only if you tick them — runs commands of the plugin being captured. If you find a way for a reviewed plugin's code to execute through Plugin Lab, or for it to write outside its output folder, please report it privately rather than in a public issue.

Use GitHub's private reporting: **Security → Report a vulnerability** on this repository. You'll get a reply within a week.
